# ZIME 0.1.5：配色、字重与独立外观选项

日期：2026-09-07。版本 0.1.5 / build 6，arm64，最低目标 macOS 13。

## 改动

- 移除候选行因为带翻译而额外施加的粗体。选中、未选中及译文状态都使用
  用户选定的字体，与设置预览的常规字重一致。
- 八套内置主题只提供颜色；从主题中移除圆角、选中方式和材质开关。
  生产主题加载器也拒绝旧内置主题中的这些覆盖，避免旧配置反向覆盖新选项。
  高级用户导入的非内置 Squirrel 配置兼容逻辑保留。
- 新增「选中效果：整行变色／下划线」与「窗口角形：圆角／直角」。
  圆角窗口与整行背景分别使用 8/5pt 半径，直角则同时为 0。
  修正零半径参与除法的问题；直角使用真正的直线闭合路径。
- 下划线时文字恢复普通正文／辅助文字颜色，不沿用只适合有色底的白字。
  对浅灰选中背景和部分深色配色增加独立强调色，保证下划线清晰可见。
- 原「原生玻璃」更名为「雾灰」，原「macOS」更名为「澄蓝」，保留
  `native_glass` / `macos` 稳定 ID。调整中性底色、选中色及 0.5pt 细边框；
  全部内置配色统一使用不透明表面，不再因主题改变模糊材质或布局。
- 主题小样和完整设置预览跟随当前选中效果与角形；配色切换不会重置它们。

候选窗由 AppKit 自绘。此前粗体、选中方式与主题绑定是应用实现策略，
不是 InputMethodKit 或 librime 的限制；本版也不宣称复制苹果原生输入法的
私有候选组件或逐像素系统外观。

设置 schema 升至 14。旧宣纸／月华／夜墨首次迁移为下划线，其他旧主题为
整行变色；旧圆角统一映射到圆角选项。之后两项独立保存。没有重复执行
v13 的竖排迁移，没有更改用户字号、页数、主题、输入、学习或翻译偏好。
外观选项走轻量重载，不要求重编译词库。

## 验证

- `tests/verify_swift_units.sh` 完整通过，未跳过外观测试。
  设置迁移、编码往返、非法枚举拒绝、轻量重载边界与配置恢复均通过。
- 新增生产 `SquirrelTheme` 与生产设置预览的 192 组合对照：8 主题 ×
  浅深色 × 2 选中方式 × 2 角形 × 12/16/32pt。Rime 配置读取为窄边界
  夹具，主题加载为真实代码；测试注入旧主题样式覆盖并确认其无效。
- 真实候选窗覆盖 384 个主题／模式／效果／角形／字号／横竖布局组合。
  另验证 3–9 候选的逐行译文、选中前后尺寸、常规字重、长释义、悬停帮助、
  VoiceOver 和原文选择索引；直角／圆角路径形状及有效坐标检查通过。
- 每套配色正文及整行选中文字对比度 ≥ 4.5:1，辅助文字 ≥ 3:1，
  下划线与背景 ≥ 3:1。680/900pt、浅深色四张主题设置渲染均通过 OCR；
  未降低原有识别门槛，旧版记录的 900pt 浅色误认此次没有重现。
- 五张 README 图片与即时真实绘制结果通过一致性检查，新增
  `appearance-controls.png` 展示雾灰配色的四种外观组合。
- `tests/verify_zime_translation.sh` 通过，包括 124,988 条源记录校验、
  地区释义、词条归属、译文展示与上屏边界；API 仅使用 mock，未访问真实
  服务或凭证。内置 SQLite 内容和 SHA-256 均未改变。
- Release App 构建、最终 ZIP/PKG 解包验证、深度严格签名校验，以及
  `tests/verify_zime.sh` 对最终 App 和安装 App 的产品校验均通过。

图片使用候选夹具经过生产绘制链生成，不是假称在同一个真实输入串下的
候选排序。当前不是隔离 UI 测试桌面，因此没有运行会驱动前台点击的
SettingsUITests；相关控件的测试入口已更新，不将其计作已通过的人工验收。
开发预览仍为 Ad-hoc App 签名，PKG 未使用 Developer ID 签名／公证。
