# ZIME 0.1.9：按输入模式隔离学习

日期：2026-09-07。版本 0.1.9 / build 10，arm64，最低目标 macOS 13。
本版按用户澄清取代 0.1.8 的跨模式共用英文词频规则。

## 模式归属

| 输入模式 | 学习记录 | 排序与控制 |
| --- | --- | --- |
| 中文模式 | `linnet_zh` + `linnet_zh_english` | 中文、英文候选在同一混排列表竞争；一起遵循中文学习策略 |
| 独立 Smart English | `linnet_en` | 独立训练；遵循英文选词学习开关，不影响中文模式 |

中文模式使用两种原生词典的编码，物理上保留各自的 Rime 用户库，但不是
两份固定位置的候选列表：同输入范围的中英文候选使用同一混排规则，原生
选词次数决定英文何时越过中文，中文也可再次超过英文。中文内部相对次序、
默认中文意图、常见英文弱匹配例外、大小写与独立英文模式行为继续保留。

Rime 根据用户库名称标记候选的语言来源，因此同步更新英文来源识别，
确保新库候选仍获得英文翻译、大小写与空格处理，而不是被误判为原文回显。
设置投影明确指定新库，使仅更新 App、保留旧语言包也能生效。

关闭中文学习会关闭中文模式里的中英文学习；关闭英文学习只影响独立英文
模式。清除中文学习包含两份中文模式用户库，清除英文学习只处理独立英文库。
新增的中文模式英文记录已纳入备份、独立类别导入导出和恢复的边界检查。
本次安装没有执行任何清除学习操作。

旧 `linnet_zh` 和 `linnet_en` 原样保留。0.1.8 共用英文记录没有可靠的模式
标签，不能准确拆分，因此不将其复制进新的中文模式英文库；新库从更新后
的实际选词开始累计。没有丢弃或重置旧库。

## 验证

- `tests/verify_rime_runtime.sh --zime-bilingual-probe` 通过。中文模式先
  学习“可以”3 次、“科研”6 次，`key` 累计 4 次可越过“可以”，7 次可
  越过“科研”；继续多选中文，再多选英文，顺序可双向改变。
- 独立英文模式连续选择 `key` 20 次，中文模式英文计数仍保持 12；中文
  模式再选一次成为 13，独立英文仍为 20。引擎重开及新进程均保持中文
  `key=13 / 科研=10`、英文 `key=20`，没有互相训练。
- 两种学习开关分别关闭时，只屏蔽自身用户记录与训练；另一模式仍能
  独立学习 `anchor`。重新开启并启动新进程，既有 `key` 计数不变。
- 测试主动将临时语言包恢复到旧版关闭中文模式英文学习的配置，由生产
  Core 投影重新部署，验证非全量安装升级路径。
- `tests/verify_swift_units.sh` 全部通过，未跳过外观测试。新增三类
  学习记录的独立便携格式往返测试；实际原生导入中文模式英文库后，清除
  中文学习会删除该测试库及中文测试库，保留独立英文库；恢复备份后的
  中文模式英文数据库字节与清除前一致。均使用隔离临时目录。
- 原生分页首尾边界、离线翻译和 mock API、候选展开代码清理、产品校验、
  Release 构建、ZIP/PKG 打包与解包签名校验均通过。
- 没有向用户前台应用注入测试文字，没有访问凭证或调用真实翻译 API；
  不宣称完成全应用前台 XCUITest 或人工逐应用输入验收。
