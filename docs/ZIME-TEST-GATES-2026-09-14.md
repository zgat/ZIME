# ZIME 核心验证入口修复

本次基于 0.1.21，范围为测试与开发文档；不修改程序行为、设置默认值、词库、
模型或安装包，不递增产品版本。

## 入口与覆盖

```sh
./tests/verify_development.sh core
```

统一执行 Swift 设置与候选窗测试、英文数据投影、ZIME 静态约束、离线／模拟在线翻译、
生产 Host 路由、上游投影与中文学习、八方案固定语料、默认原生回归及六个专项：
快捷键、双语学习、数字混输、大小写、分页、八方案兼容按键。

原有四条命令继续可用，但不是互相替代关系：Swift 单元测试不等于 Host 路由测试，
双语专项不等于所有按键行为，静态检查也不等于运行时验收。

## 修复内容

- 默认原生回归显式部署其直接使用的兼容方案；固定语料测试在临时目录中部署八方案。
  公开模式列表仍严格验证为全拼与英文两项，不通过改变产品默认值迁就测试。
- 旧设置中的双拼选项按当前产品规则迁移为全拼；迁移与原生兼容索引分开验证。
  设置投影后重新编译测试直接选择的兼容方案，避免读取旧的编译配置；简繁开关按
  名称与值精确检查，不再被其他开关的同值误导。快速配置重载使用显式兼容方案
  测试环境，保留 20 次同秒更新与 11 个目标文件的边界检查。
- 原生脚本提供 `--list-probes`，拒绝未知参数和多余参数；编排检查验证可用参数、
  原生分支与统一入口的覆盖，不再按某个参数字符串在文件中出现的次数判断正确性。
- 候选数量投影覆盖全部 3–9。分页边界必须是被消费的无操作，不允许漏出标点。
- 更新回车原文提交、被动预测的空格／回车退出规则；兼容 Tab 配置测试完成后恢复
  当前 `pass` 默认值。候选高亮辅助函数允许“目标已经选中”的合法无操作。
- 冷启动排序在选词学习之前检查；空格边界测试显式高亮所需词条，避免依赖此前
  学习造成的排序。词库来源不再被误当作候选语言，合法 Emoji 不再被判成原文回显。
- 英文标准词表可达性复用统一来源检查，接受学习后合法的 `user_table` 候选，
  并增加先选词再查询的回归；不把原文回显或反查候选当作词表命中。
- 禁用译词测试使用当前公开方案与正确查询，并验证可见、禁用、恢复三个状态，
  避免错误前缀或不存在的候选造成假通过。
- 原“展开候选”测试更名为原生跨页绝对索引测试，保留其分页覆盖，不恢复展开界面。
- Swift SDK 模块缓存默认留在工作区；跳过外观的运行明确输出 `PARTIAL PASS`。
  `CONTRIBUTING`、README 与开发指南使用同一核心入口。

## 本地验证结果（2026-09-14）

最终按核心入口的三个组成部分分组复核，均以最后一次运行的退出状态为准：

| 命令 | 结果与范围 |
| --- | --- |
| `./tests/verify_development.sh swift` | PASS；含外观／候选窗、静态约束、翻译、生产 Host 路由 |
| `./tests/verify_english_data_projection.sh` | PASS；147,718 个英文词、4,585,114 条索引行及正反向释义约束 |
| `./tests/verify_development.sh rime` | PASS；默认原生套件、六个专项、上游投影、学习与同步、设置迁移 |

八方案固定语料共 1,776 条全部通过，故意修改双拼映射的负向测试正确拒绝错误。
快速配置重载 20 次通过；候选数量覆盖 3、4、5、6、7、8、9。
另行验证跳过外观时输出 `PARTIAL PASS`；Shell／Ruby 语法、编排参数及差异格式检查通过。

本地日志保存在忽略目录 `build/test-gate-repair-2026-09-14/`，最终分组日志为
`zime-swift-final.log`、`zime-english-final.log` 和 `zime-rime-final.log`。
中间失败或定向诊断不作为最终整组通过的证明。

## 验证边界

测试只使用临时用户目录；在线翻译使用模拟传输，不读取凭据、不发送真实翻译请求。
默认会清理隔离现场；设置 `LINNET_KEEP_FAILED_RIME_FIXTURE=1` 可保留失败数据用于排查。

核心入口不含重新构建／安装 App、真实客户端输入 UAT、GitHub CI 或发布验收。
本次未修改继承的 Linnet 历史 CMS 迁移授权；其完整发布 owner 检查仍在历史迁移
契约处失败，不能把本次核心结果描述成整个旧发布体系通过。与本次入口有关的
CI 分组约束已单独核对。
