# ZIME 0.1.2：翻页边界与菜单栏去重

日期：2026-09-07。版本 0.1.2 / build 3，arm64，最低目标 macOS 13。

## 行为

- 中文和智能英文候选中，`-` 上一页，`=` / `+` 下一页（包含 Shift+等号）。
  到首尾页仍消费按键，但不提交词语或符号，不修改输入串、候选和高亮。
- 该策略仍由同一个原生 Rime processor 负责；没有在 Host 叠加另一套普通
  候选翻页逻辑。无候选、原始 ASCII、代码片段以及系统快捷键保留原有处理。
  方括号在边界的标点行为未改动。
- 独立中英文状态栏图标默认关闭，旧配置缺少该选项时也默认关闭。
  macOS 输入源菜单、设置入口、Shift 切换和光标附近短暂模式提示不变。
  高级 YAML 配置仍可显式设置 `status_icon/show: true` 恢复独立指示器。

## 验证

- Release 构建成功；原生插件使用 `-Wall -Wextra -Werror` 构建。
- `tests/verify_rime_runtime.sh --zime-paging-probe` 使用隔离数据和真实 librime：
  中文与英文正常翻页、末页返回第一页、边界连续按 20 次、加号的 Shift 修饰、
  空闲符号、原始 ASCII、Control/Option/Command 快捷键、Caps Lock 与 Shift
  切换。断言边界不产生 commit，不修改候选或输入串，不触发展开请求。
- `tests/verify_zime.sh` 检查核心身份、菜单栏默认策略和打包资源。
- App 内原生插件的 UUID 与构建插件一致；代码段内容 SHA-256 一致。
  打包过程可能改变链接/签名元数据，因此不把整文件比较当作代码段比较。
- ZIP / PKG 均经解包、完整 App 签名和四类离线数据包检查。
- 本机仅更新 App，保留词库、配置和学习数据，并保留旧 App 回退副本。

范围说明：上游 `--profile-key-matrix-probe` 要求固定八种中文方案，而 ZIME
只提供全拼与智能英文，因此该探针在方案清单检查处退出。本次使用实际产品
方案的专用原生探针，没有宣称全部上游测试通过；也没有将测试引擎结果冒充
真实文本客户端的人工敲字验收。
