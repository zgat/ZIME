# ZIME 0.1.2 安装与使用

> 历史文档：以下说明对应旧版 0.1.2 开发交付。0.1.16 的首次 GitHub 预览发布
> 仅包含源码和说明，不提供安装包。旧 `install-zime` / `update-zime-app` 的升级路径
> 尚未移植已本地验证的完整 Contents 交换与运行状态检查，不建议用于覆盖现有安装。
> 当前发布范围以 [0.1.16 版本说明](releases/ZIME-0.1.16.md) 为准。

ZIME 0.1.2 支持 Apple Silicon 和 macOS 13 及以上版本。当前交付是本地
Ad-hoc 签名的开发预览版，没有 Apple Developer ID 公证；请只安装你已核验
校验和、并信任其源码和构建来源的副本。

## 推荐：ZIP 安装

1. 解压 `ZIME-0.1.2-arm64.zip`。
2. 在终端进入解压后的目录，运行 `./install-zime`。
3. 打开“系统设置 → 键盘 → 文本输入 → 编辑”，添加“ZIME 简体中文”或
   “ZIME 繁體中文”。如果系统没有立即刷新输入法列表，请注销并重新登录。

安装脚本只写入当前用户的 `~/Library/Input Methods/ZIME.app`，升级时会原子
替换旧 App，不会删除 `~/Library/Application Support/ZIME` 中的本地学习数据。

也可以打开 `.pkg`。该包把同一个 App 和完整离线词库安装到当前用户域，并在
安装完成后注册输入源。按 macOS 提示授权后，在键盘设置中添加 ZIME。

## 已安装但列表中没有 ZIME

早期的 0.1.0 PKG 缺少安装后注册步骤。更新后的 PKG 已补齐该步骤；如果已安装
早期包，可以在当前登录用户的终端中运行以下命令，无须重装词库：

```sh
"$HOME/Library/Input Methods/ZIME.app/Contents/MacOS/ZIME" --request-first-install-authorization
```

随后重新打开“系统设置 → 键盘 → 文字输入 → 编辑 → ＋”，在“简体中文”中
选择“ZIME 简体中文”，点击“添加”。繁体输入源位于“繁体中文”分类中。
命令成功表示已发起注册/授权请求，仍需按系统提示完成授权和添加。如果重新
打开设置后仍未刷新列表，可保存工作后注销并重新登录。

## 输入方式

0.1.2 修复了候选翻页边界：`-` 到第一页后继续按不操作，`=` / `+` 到最后一页
后同样不操作，不会提交候选或输入符号。没有候选时仍按正常符号输入规则处理。
默认关闭额外的中英文状态栏图标；设置入口仍在 macOS 标准输入源菜单中，
Shift 切换中文/智能英文和光标附近的短暂模式提示保持不变。

0.1.1 默认竖排列出每个候选及对应译文；外观页的候选数量下拉框可选 3–9。
“翻译”页可选择 OpenAI 兼容接口、DeepL、百度、腾讯，填写各自凭据后点
“保存翻译设置”。云翻译默认关闭；启用后仅补全当前页缺少本地译文的候选。
密钥保存在 macOS 钥匙串，本地词典优先，不会自动把译文追加到正文。

已装有完整 0.1.0 词库时，可用 ZIP 中的 `update-zime-app` 仅更新 App，避免
重复安装词库；该脚本会短暂停止 ZIME，并保留旧 App 用于回退：

```sh
./update-zime-app "$PWD/ZIME.app"
```

- 默认使用全拼；候选主文本是实际候选，灰色副文本是本地翻译。
- 中文拼音候选显示英文释义，英文单词候选显示中文释义。
- 默认按 Tab 进入“译文选择”状态；数字键提交对应译文，回车始终提交原始输入。再次按 Tab
  或按 Escape 回到原文候选。没有主动进入译文状态时，翻译不会上屏。
- 轻按 Shift 在中文和智能英文之间切换；Caps Lock 保持原始 ASCII 输入。
- 支持首字母缩写、拼写模糊/纠错、多词候选、本地学习、上下文排序、联想和
  Emoji。候选生成和本地词典查询在本机执行；云翻译仅在你明确开启后请求服务商。

## 卸载

运行随 ZIP 提供的 `./uninstall-zime`。默认保留本地学习数据；如需一并删除，
运行 `./uninstall-zime --purge-data`。
