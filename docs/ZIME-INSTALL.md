# ZIME 0.1.17 安装与使用

支持 Apple Silicon、macOS 13 及以上版本。开发预览采用 Ad-hoc 签名，
尚无 Apple Developer ID 签名或公证；只安装你信任并核对 SHA-256 的副本。
GitHub 自动生成的 Source code ZIP/TAR 是源码，不是安装包。

## 选择下载

- `ZIME-0.1.17-arm64.zip`：推荐，App + 全部离线词库 + 新版 LTS 模型。
- `ZIME-0.1.17-arm64.pkg`：同一套完整数据，通过 macOS 安装器安装到当前用户。
- `ZIME-0.1.17-arm64-core.zip`：仅更新 App 和运行库；必须已有兼容的完整词库。
  **不会升级万象词库或 LTS 模型**，本次升级建议选择完整包。
- `wanxiang-lts-zh-hans.gram`：源码构建使用的锁定模型镜像，不是安装器。
- `SHA256SUMS`：发布资产校验和。

## 推荐：ZIP 安装或升级

1. 保存正在输入的内容、关闭 ZIME 设置；不要在安装期间继续使用 ZIME。
2. 解压完整 ZIP，在终端进入解压后的目录，运行 `./install-zime`，不要用 sudo。
3. 首次安装按系统提示授权，并在“系统设置 → 键盘 → 文本输入 → 编辑”中添加
   “ZIME 简体中文”或“ZIME 繁體中文”。列表未刷新时，保存工作后注销再登录。

仅更新 Core 时，在 Core ZIP 解压目录运行 `./update-zime-app`。
升级会暂时切换至可用的 ASCII 键盘，正常退出输入法和设置，不强制结束进程。
如果设置等待保存/撤销，或输入法没有退出，安装会停止；处理提示后重新运行即可。

安装位置：

- App：`~/Library/Input Methods/ZIME.app`
- 离线数据：`~/Library/Application Support/ZIME/Data` 和 `Runtime`
- 用户词频和设置：原有 `UserData` 保留，不随词库覆盖。

升级交换 App 的完整 Contents，保留已经注册的 App 目录；不会重新请求首次安装授权。
安装前会校验 App 签名、身份、架构和完整词库。失败时尝试恢复安装前 App/数据；
旧版本和学习数据快照保留在 `~/Library/Input Methods/.zime-install-…`，终端会输出准确路径。
不要在验证新版本前删除该备份。

突然断电、安装器被强制关闭或输入法异常重启时，不承诺跨目录的整体原子性；
检测到未完成安装标记会拒绝再次覆盖。请保留备份和报错信息，先退出 ZIME 并反馈，
不要直接删除标记或手工覆盖 UserData。

## PKG

打开完整 PKG，选择“仅为我安装”。PKG 不直接覆盖正在运行的输入法：先把材料放入
`~/Library/Application Support/ZIME Installer/0.1.17`，再调用与 ZIP 相同的升级事务。
该目录为可重复执行的安装材料，不是日常使用的输入法；不应从中直接启动 ZIME.app。
安装失败时可以进入该目录运行 `./install-zime` 查看终端提示。
未公证预览可能被 Gatekeeper 拦截；请核对来源和校验和，不要全局关闭系统安全检查。

公开测试覆盖了包解压、签名、数据清单和隔离目录升级/失败回滚；未在本次测试中
替换用户当前输入法，也未把包级测试表述为所有系统版本上首次授权界面的验收。

## 输入方式

- 默认全拼；每个候选逐行显示译文，候选数可选 3–9。
- Tab 切换原文/译文，数字键选词；Enter 提交原始输入，不选择高亮候选。
- Option-Tab 智能补全；快捷键可在设置中直接录入。
- Shift 切换中文/智能英文，Caps Lock 保持原始 ASCII。
- `-` / `=` / `+` 翻页，到边界停留；无候选时正常输入符号。
- 中文模式内中文、英文、Emoji 共同参与显示排序；独立英文模式保持独立学习。
- 本地词库优先；云翻译默认关闭。翻译页可配置 OpenAI 兼容接口、DeepL、百度、
  腾讯。仅启用后补全缺少本地译文的候选，凭据保存于 macOS 钥匙串。
- 来源标签只显示，不上屏；本地注释可选悬停显示，在线译文字段完整提交。

## 卸载

ZIP 中的 `./uninstall-zime` 默认保留学习数据。
`./uninstall-zime --purge-data` 会删除个人学习和设置，仅在确定不再需要时使用。
