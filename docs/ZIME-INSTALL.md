# ZIME 0.1 安装与使用

ZIME 0.1 支持 Apple Silicon 和 macOS 13 及以上版本。当前交付是本地
Ad-hoc 签名的开发预览版，没有 Apple Developer ID 公证；请只安装你已核验
校验和、并信任其源码和构建来源的副本。

## 推荐：ZIP 安装

1. 解压 `ZIME-0.1.0-arm64.zip`。
2. 在终端进入解压后的目录，运行 `./install-zime`。
3. 打开“系统设置 → 键盘 → 文本输入 → 编辑”，添加“ZIME 简体中文”或
   “ZIME 繁體中文”。如果系统没有立即刷新输入法列表，请注销并重新登录。

安装脚本只写入当前用户的 `~/Library/Input Methods/ZIME.app`，升级时会原子
替换旧 App，不会删除 `~/Library/Application Support/ZIME` 中的本地学习数据。

也可以打开 `.pkg`。该包把同一个 App 和完整离线词库安装到当前用户域；安装
后若输入法列表尚未出现，请注销并重新登录，再在系统设置中添加。

## 输入方式

- 默认使用全拼；候选主文本是实际候选，灰色副文本是本地翻译。
- 中文拼音候选显示英文释义，英文单词候选显示中文释义。
- 默认按 Tab 进入“译文选择”状态；数字键或回车提交选中的译文。再次按 Tab
  或按 Escape 回到原文候选。没有主动进入译文状态时，翻译不会上屏。
- 轻按 Shift 在中文和智能英文之间切换；Caps Lock 保持原始 ASCII 输入。
- 支持首字母缩写、拼写模糊/纠错、多词候选、本地学习、上下文排序、联想和
  Emoji。所有候选与翻译查询均在本机执行。

## 卸载

运行随 ZIP 提供的 `./uninstall-zime`。默认保留本地学习数据；如需一并删除，
运行 `./uninstall-zime --purge-data`。
