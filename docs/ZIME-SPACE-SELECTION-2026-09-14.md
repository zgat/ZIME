# ZIME 0.1.21：空格选择高亮候选

状态：本地预览，未发布。版本 0.1.21，构建号 22。

## 行为

- 正在输入时，空格选择当前页高亮的原文或译文，而不是固定选第一项。
- 数字按当前位置选词；Enter 与小键盘 Enter 仍提交原始输入。
- 中文候选和译文不自动附加空格；独立英文原文候选沿用尾随空格开关。
- 分段选词保留确认的前缀和未选择的尾串；译文完整提交，不带来源标签或悬停注释。
- 空闲时空格交给应用；仅有下一词预测时插入普通空格，不选预测项。
- 用户明确录入的快捷键继续优先，不迁移或覆盖既有设置。

原文通过原有 Rime 确认路径选词；译文通过原有分段译文选择接口提交。
两者都保留选词学习，不新增绕过学习的客户端直接插入逻辑。
程序更新不更换内置词库与模型。
