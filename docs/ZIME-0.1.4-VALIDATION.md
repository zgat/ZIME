# ZIME 0.1.4：词条归属、译义去重与注释分层

日期：2026-09-07。版本 0.1.4 / build 5，arm64，最低目标 macOS 13。

## 改动

之前的索引把 CC-CEDICT 的简体和繁体表头合并成一个字符串键，丢失来源。
例如 `你 你 [ni3]` 与 `妳 你 [ni3]` 都落在“你”下面，地区筛选后仍有重复
you 和不属于当前繁体字形的说明。本版重建本地 SQLite 索引（user_version=2）：

- 保存全部 124,988 条源记录的简繁字形、读音、完整有效释义和排序信息。
  简体按源简体表头查询，繁体按源繁体表头查询；反向英文索引仍独立保留。
  “你”与“妳”在繁体查询中不再互相混入。
- 同级来源轮流提供义项，不让某个多义来源占满候选说明。简体“发”同时
  展示 `to send out / hair`，不会因优先匹配“發”而丢掉“髮”的不同词义。
- 相同展示译义合并，明确的说明性重复译义也合并，但不会合并
  `capital (city)` 和 `capital (finance)` 这类不同的辨义限定。
- 候选行与详情分离：“你”为 `you (informal)`，“妳”为 `you (female)`。
  将拼音引用、明确的 Note、举例、异体字和读音补充等注释移入详情，保留
  informal、female、city、bound form 等区别意义或用法的限定。
  不是 AI 摘要，不删全部括号，不按长度猜测哪段是注释。未知格式、只有
  括号的语法释义、未闭合括号等保守保留。
- 本地词典向候选窗传送独立的展示文字、原始译文候选、完整详情。
  JSON 内部格式处理引号及分隔符，不把内部标记或错误 payload 显示给用户。
  悬停帮助和 VoiceOver help 保留当前地区的完整说明与词条来源。
- 普通候选仍只上屏原文；Tab 仍进入译文候选状态，原始完整译文不使用
  展示文字替代，不因移动注释或 UI 宽度限制而被截断。重复译义只保留一项。

沿用 0.1.3 的地区分组、macOS 配色，以及 0.1.2 的翻页边界和状态栏去重。
没有接入新词库、修改云翻译服务、发送输入上下文或改变默认联网许可。
词典及衍生说明仍为 CC BY-SA 4.0；更新了 App 内附带的许可说明。

## 验证

- `tests/verify_zime_lexicon.rb`：独立逐条比对源 gzip 与最终 SQLite 的
  124,988 条记录，检查字形、读音、完整有效释义、优先级；另用微型夹具
  验证重复构建字节一致、JSON 引号往返、拒绝覆盖已有输出及数据库完整性。
- `tests/verify_zime_translation.sh`：你/妳归属、发/發/髮不同词义、地区缓存
  切换、原始详情、词义限定、嵌套/不完整括号、非拼音方括号、云回退排除和
  原文提交边界通过。在线 API 仅使用 mock，无真实网络或凭证访问。
- `tests/verify_candidate_window_interaction.sh`：真实候选窗渲染链覆盖
  简繁两组、3–9 候选、12/16/32pt；逐行译义、注释不外泄、原生 tooltip、
  VoiceOver 详情、选择索引和隐藏清理。原有长释义换行与各主题布局仍测试。
- 完整 Release App 构建通过，产品验证检查安装资源中的新索引逐字节一致。
- `tests/verify_swift_units.sh --skip-appearance-preview` 最终通过。该套件中的
  四张 README 图与即时渲染差异均为 0；主题 OCR 专项没有包含在此次通过声明中。

预览图是本地词条展示夹具通过生产渲染链生成的，不是同一个真实输入串的
候选排序截图，也不冒充真实文本客户端的人工敲字验收。
设置页主题 OCR 的已知误认见 0.1.3 验证记录；本次没有改主题或放宽该门槛。
