# ZIME 0.1.3：地区释义与 macOS 配色

日期：2026-09-07。版本 0.1.3 / build 4，arm64，最低目标 macOS 13。

## 释义策略

- 不采用“提炼核心译义”、删括号或裁掉同义词的方案。通用释义的语法、
  礼貌程度和使用说明保留。正常竖排候选限制宽度并由 TextKit 自动换行；
  不修改候选主文本、源索引或上屏内容。
- 跟随 Rime 当前 `traditionalization` 选项，而不是从字形猜测地区：
  简体组为通用 + 大陆；繁体组为通用 + 港澳台 + 新加坡/马来西亚。
  后两地归入繁体组是本产品的用户偏好，不代表简繁与地区一一对应。
- 本地 SQLite 原始数据不变，按明确的 `(Tw)`、`(HK)`、`(PRC)`、
  `(Singapore, Malaysia)` 等标签投影，缓存键含地区。未标注、含糊标签和
  普通地理描述保留，不用关键词扫描推断用法。参考
  [CC-CEDICT 标签说明](https://cc-cedict.org/wiki/labels)。
- “你/妳”包含大陆与台湾差异的混合说明，按完整源字符串精确匹配后拆分，
  保留对应地区的说明。一般的 informal/courteous 区别不变。若词典以后
  改写这段文字，旧规则不再匹配，原文保留供重新审核。
- “土豆”：简体保留 potato；繁体保留通用 potato 及 `(Tw) peanut`。
  “德士”：简体提示当前地区暂无本地释义；繁体保留新马的 taxi 义。
  全部释义被明确地区规则排除时，不用引擎旧注释或云请求填回被排除内容。
- 原有候选行最多展示两个释义、Tab 提供最多三个译文候选的数量规则不变。
  原生悬停帮助展示当前注释包含的完整释义，VoiceOver help 同样保留；
  更换候选、模式提示及隐藏窗口时清理旧 tooltip。使用
  [AppKit tooltip](https://developer.apple.com/documentation/appkit/nsview/addtooltip(_:owner:userdata:))，
  显式保持 owner 生命周期；不是新增独立的选中词侧栏。

范围：CC-CEDICT 不是完整的地区专用词典，不能保证每个词义都有地区标签。
这一版是中文本地释义的保守筛选；未标注地区的在线 API 结果和智能英文
的中文释义不做地区推测，也不宣称已提供完整的港澳/台湾/新马独立词典。
候选截图使用本地词库数据及生产候选窗渲染链，是隔离的渲染夹具，不冒充
真实文本客户端人工输入验收。

## 外观

新增第八个主题 `macos`，包含浅色和深色两套。中性灰白/深灰背景、蓝色
选中行、白色选中文字，使用不透明背景避免受应用底色染色。
不是系统强调色的动态镜像，也不是 macOS 原生输入法界面的逐像素复制。
设置入口为「外观 → 主题 → macOS」，外观模式支持系统/浅色/深色。
不覆盖原有主题选择、字号、候选数量、学习记录或词库。

- Release 完整构建、产品身份/arm64/资源检查通过。

  防护，以及候选索引/上屏边界通过。API 使用 mock，不访问真实凭证或网络。

  读写、投影、候选展示/交互、运行时与 IPC 等。不是完整 Swift gate 的通过声明。

  3–9 候选、12/16/32pt；长释义完整保留/换行/命中区域/AX 选择；
  隐藏后 tooltip 清理；四张 README 图片与即时重渲染的差异均为 0。

  均已生成并目视检查，八个主题卡片、16 个样例完整可见。
