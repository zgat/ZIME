# ZIME 验证体系跟进

基于 0.1.21；本轮修改测试、构建/CI 和文档，不修改产品输入逻辑、词库或用户设置。
不提高产品版本，不自动安装或发布。

## 已修复的验证边界

- 按实际产品身份分流发布门：ZIME 验证自身身份、Ad-hoc 策略、附件与暂存安装器，
  Linnet 保留原 CMS 检查。旧证书配置、迁移指纹和归档工作流的原始摘要不变。
- 统一 Core 接入安装回滚、隐私、发布契约与 CI 编排；保留全部原生行为回归。
- App 门改用 ZIME 构建产物，Settings 隔离测试从当前配置取得产品路径/身份，
  同时保护真实 ZIME 与 Linnet 数据；点击测试的 App 路径和对话框标题与 ZIME 一致。
- 新增 4,096 轮、64 次会话重建的确定性压力回归；报告周期 p99 与本进程 RSS，
  不把短时压力测试冒充长期泄漏检测。
- 新增 LLVM 逐文件覆盖率：翻译、设置模型、候选翻译、安装事务及生产依赖；
  实测行覆盖率 29.03%、函数覆盖率 31.25%，不是全项目覆盖率，不设置虚假的高覆盖结论。
- 新增实际 ZIP/PKG/模型/manifest 校验，以及错误身份、版本、附件损坏、危险路径和链接等负向测试。
- PR / 手动 CI 配置 macOS 15 与 26，保留真实测试报告；发布工作流只生成验证候选，
  不导入旧 CMS 密钥，也不自动写 GitHub Release。
- 增加显式授权的在线服务烟雾测试与人工验收收据校验；未执行不能记作 PASS。
- Swift 临时目录测试的前置编译也改用工作区模块缓存。
