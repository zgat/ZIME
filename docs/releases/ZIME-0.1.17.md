# ZIME 0.1.17 开发预览

Apple Silicon，macOS 13+。完整 ZIP / PKG 包含 App、离线词库及模型；
Core-only ZIP 仅更新 App 和运行库。**此次建议使用完整包**，以取得新词库和模型。
安装步骤见 [安装说明](https://github.com/zgat/ZIME/blob/v0.1.17/docs/ZIME-INSTALL.md)。

## 上游更新

- 万象词库：17.3.0 → 17.9.9，锁定 `d6e8e2c8a3ea2d2fa324f87919f52324fae5cc23`。
  更新选用的字词表及拼音投影；没有整体替换 ZIME 的 schema、Lua 或排序策略。
- Wanxiang LTS：锁定 2026-09-05 资产，420,339,756 字节，SHA-256
  `654d7f1fe4b1bf3d425f8c0a44ac61423ded58c784267b4df03256030d72233f`。
  在本 Release 保留同哈希模型镜像，避免可变 LTS 标签影响旧版本构建。
- librime-octagram：修正罕见 Unicode 字符编码碰撞，更新 BSD-3-Clause 归属。
- librime-lua：更新共享词典查找与 GC 调度；内嵌 Lua 5.4.8 → 5.4.9，未迁移到 5.5。
  保留 ZIME 既有生命周期修复和加载限制。
- Squirrel、librime Core、rime-ice、Hallelujah、Plum 及 predict 本次保持原锁定版本。

ZIME 的中英文分模式学习、Emoji 排序、按键规则、界面和翻译解析没有改设计。
仍保留 42 条人工核对的读音纠错，并重新验证 104,526 条低优先级补充词。
阿贝尔奖已进入万象主词库，不再从补充词库重复收录。

## 安装包恢复发布

- ZIP 和 PKG 使用同一升级事务；不强制结束进程，保留输入源注册目录。
- 完整更新校验并交换 App / Data / Runtime；Core-only 验证保留词库的兼容性。
- 安装前备份学习数据，安装过程中不覆盖 UserData；失败尝试回滚，保留准确备份路径。
- PKG 只先投放安装材料，不由系统安装器提前覆盖运行中的 App；禁用 Bundle 重定位。
- 不使用隐藏启动选项，不在普通升级时重新请求首次安装授权。

## 预览限制

App 使用可验证的 Ad-hoc 签名；PKG 未 Developer ID 签名，均未 Apple 公证。
没有开启自动更新频道。首次输入源授权仍需用户按 macOS 提示完成。
回滚测试在隔离目录执行，本次未替换用户当前输入法；微信截图兼容性没有扩大承诺。
突然断电或强制关闭安装器可能留下中间状态：会保留标记并阻止继续覆盖，请保留备份反馈。

语法和词库更新不保证每个新词或整句都正确；本地翻译覆盖率没有因换拼音词库而自动扩大。
离线优先和云翻译隐私边界不变；没有使用真实用户 API 凭据执行测试。
