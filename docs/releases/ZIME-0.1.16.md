# ZIME 0.1.16 开发预览（源码）

面向 Apple Silicon、macOS 13 及以上版本的本地优先双语输入法。
这是 ZIME 的首次 GitHub Release，同步此前本地迭代至 0.1.16 / build 17。

## 主要功能

- 中文全拼、简拼、多字候选、模糊匹配；英文补全、纠错、大小写兼容和常用缩写。
- 每个候选逐行显示译文，候选数可选 3–9；主题颜色、选中效果和圆角独立设置。
- Tab 切换原文/译文，数字键选词，回车提交原始输入；快捷键可以直接录入。
- 中文模式中英文与中文共同学习排序，独立英文模式维护自己的学习记录；Emoji 也参与排序。
- 默认离线；可选 OpenAI 兼容接口、DeepL、百度与腾讯翻译，密钥保存在本机钥匙串。

## 本版翻译改进

- 在线候选标明 `腾讯:`、`百度:`、`DeepL:` 或 `ai:`，标签只显示、不上屏。
- 本地已有可用译义时不请求在线服务；在线译文字段完整保留，不按词典规则清理或拆分。
- 本地词库保留全部 124,988 条源词条、199,654 段原始内容，区分译义、注释和引用。
- 括号按内容分类，保留语义限定、完整语法释义和未知内容。引用按字形与读音匹配，并防止循环。
- “你／妳”显示 `you`，“费城”显示 `Philadelphia, Pennsylvania`，“世博”显示 `World Expo`。
- 完整本地注释可在设置中开启悬停显示；翻译设置使用统一的应用/撤销流程。

## 发布范围与限制

本次仅发布源码和版本说明，**没有附带可执行安装包**。GitHub 自动提供的 Source code
ZIP/TAR 是源码归档，不是输入法安装器。

本地开发版已完成 0.1.16 安装核验，但公开安装/升级脚本仍需修复和单独验收，因此暂不
上传旧流程生成的 ZIP/PKG。项目尚无 Developer ID 公证版本，也未开通自动更新频道。
从源码构建需要 Xcode 和仓库锁定的依赖、词库，不能直接双击源码归档使用。

翻译词库不保证覆盖所有新词或整句；无法可靠解析的引用不会编造释义。在线响应最多
4,096 UTF-8 字节，超限整体拒收、不静默截断。微信截图能否包含候选框仍与宿主应用和
系统输入会话有关，本版不宣称已普遍解决。

验证记录见仓库中的翻译、候选交互及 0.1.16 本地安装文档。真实 API 服务使用固定
JSON/模拟传输验证，未代替用户实际账号的联网、额度和可用性测试。
